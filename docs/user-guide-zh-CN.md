# 使用说明

## 桌面免安装版

从 [GitHub Releases](https://github.com/suosijieniwo/holly-crm-chat-detail-crawler/releases/latest) 下载 Windows 免安装 exe，软件界面显示中文名称「客服聊天记录导出工具」。需要 Windows x64、Microsoft Edge、可访问后台的网络与有查询权限的账号，不需要安装 Node.js。

1. 双击 exe，点击“打开后台”。
2. 在专用 Edge 中登录，设置筛选条件并点击网页原有的“查询”。
3. 回到桌面窗口，确认当前查询后点击“开始导出”。首次导出时选择保存文件夹，取消选择不会启动采集。也可以先在底部点击“选择保存位置”。
4. 选好位置后底部保留“打开 Excel”和“打开文件夹”，完成后可直接打开结果。保存位置会自动记住，重启后继续沿用；空闲时点击路径旁的“更换”选择新文件夹。更换不会移动或删除旧文件，新的 Excel 会在下次导出完成后显示。
5. 点击“停止并保留进度”会等待在途操作收尾，同一窗口可以继续下一次导出。

在“当前查询”下方勾选要导出的“用户”“客服”“机器人”，可自由组合，至少选择一类。默认选择用户和客服，设置保存在本机并在重启后沿用。系统通知始终不导出；角色选择只控制最终写入 Excel 的消息内容，不改变后台筛选条件。

## 源码批处理入口

此入口需要先安装项目依赖，并完成 `npm run build`。运行时需要 Node.js 24 或更高版本。

1. 双击根目录的 `启动聊天记录导出工具.bat`。
2. 在自动打开的专用 Edge 中手动登录。该浏览器使用独立登录目录，不读取日常 Edge 的默认用户配置；登录成功后工具会自动进入“会话记录高级查询”。
3. 在网页设置日期、渠道、标签、用户等筛选条件，再点击网页原有的“查询”。
4. 核对筛选结果后，点击右下角工具面板的“开始导出”。开始后不要修改筛选条件。
5. 工具会固定当前筛选对应的全部会话，再逐条读取完整消息历史。完成后自动生成 Excel，并打开桌面输出文件夹。

## 输出内容

- `会话汇总`：每个会话一行，包含会话、访客、时间、坐席、渠道、状态和所选角色的导出消息数等字段。页面声明数属于服务器原始口径，不能直接比较。
- `消息明细`：按所选角色导出用户、客服和/或机器人消息，按时间从早到晚排列；系统通知始终排除。超长内容分为多行并标注分段，汇总仍按原消息计数。
- 图片、语音、视频和附件只保留网页返回的链接，不下载文件实体。
- 所有网页文本都按 Excel 纯文本写入，不会作为公式执行。

## 中断和继续

点击“取消”或遇到网络/登录问题时，已完成内容会保存为本机断点。下次使用完全相同的筛选条件开始导出，工具会继续未完成的会话。

成功会话不重复抓取，失败和部分成功会话重新尝试。旧版断点需要重新采集一次，以修正发送方分类与媒体链接遗漏。取消时工具等待在途请求结束后保存，退出后不会继续修改断点。

Excel 生成不代表每段会话完整：请查看“导出状态”。存在无法识别的发送方、缺失媒体链接或无法确认历史完整性时会标记部分成功，并保留断点。桌面版可在同一窗口重新查询和开始；批处理入口需重新启动工具，用相同筛选继续。

## 安全范围

工具只允许以下两个只读动作：

- `app.media.queryChatRecord`：读取当前筛选的会话列表。
- `app.media.getSessionRecord`：读取指定会话的完整消息历史。

工具自身发起的采集请求中，任何其他动作名、其他域名、PUT、PATCH、DELETE 请求都会被本地安全策略拒绝。该策略不接管后台网页的全部请求。工具不会主动修改标签、备注、状态、工单或发送消息。

## 本机文件位置

- 专用登录状态：`%LOCALAPPDATA%\CustomerChatExporter\edge-profile`
- 未完成任务：`%LOCALAPPDATA%\CustomerChatExporter\jobs`
- 桌面版最终 Excel：首次选择或后续更换的保存文件夹
- 保存位置设置：`%LOCALAPPDATA%\CustomerChatExporter\desktop-settings.json`
- 批处理入口最终 Excel：桌面 `客服聊天记录导出`

最终 Excel 和未完成任务可能包含聊天内容，请按公司数据规范保管，不要上传到非授权位置。

保存位置不能设为 `%LOCALAPPDATA%\CustomerChatExporter` 或其子文件夹，避免清理运行数据时误删 Excel。

## 清理本机数据

- 双击 `清除未完成任务.bat`：仅删除未完成任务断点，保留专用登录状态和已导出的 Excel。
- 双击 `清除专用登录状态.bat`：仅退出并清除工具专用登录环境，保留任务断点和已导出的 Excel。
- 批处理操作会要求输入 `YES` 二次确认，其他输入均取消；桌面版设置使用独立确认对话框。
