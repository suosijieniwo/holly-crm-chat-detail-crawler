# 授权验收清单

## 桌面版保存位置（v1.0.1）

以下项目已使用最终单文件 exe 与虚构会话完成验证，不涉及真实业务样本。

- [x] 首次开始导出时弹出文件夹选择，取消不会开始采集。
- [x] 自选文件夹实际收到 Excel，文件可回读且有两张工作表。
- [x] 选好后显示“打开 Excel”“打开文件夹”，分别打开结果文件和保存目录。
- [x] 空闲时可更换目录；更换不会移动或删除旧 Excel。
- [x] 运行及停止收尾期间禁止更换；停止与续跑正常。
- [x] 重启后沿用已选择的保存目录。
- [x] 运行数据目录及其子目录不可作为保存位置，避免清理时误删 Excel。

## 小样本验收

- [ ] 在专用 Edge 登录，仅使用“会话记录高级查询”页面。
- [ ] 设置能返回 3—10 个会话的筛选并点击网页原有的“查询”。
- [ ] 点击右下角“开始导出”，确认筛选会话数与 `会话汇总` 行数一致。
- [ ] 随机核对至少 3 个会话：消息数量、时间顺序、发送方、可见文字和媒体链接。
- [ ] Excel 只包含 `会话汇总` 与 `消息明细` 两张工作表，中文显示正常。

## 边界验收

- [x] 混合发送方回归仅导出 visitor/agent，人工消息携带 robotName 不误判。
- [x] 长文本分段不重复计数，独立图片/语音/视频字段保持链接；缺失链接标部分成功。
- [x] failed/partial 续跑、旧版本分类迁移、完整 success 跳过、完成 ID 去重。
- [x] 多线程取消与保护停止收束在途任务、保存独立快照；Excel 写出期间取消保留断点。
- [x] 写出/保存错误可见；列表失败和开始前取消结束等待并停止查询观察。

- [ ] 多页查询结果可完整固定，重复会话只保留一份。
- [ ] 长会话可取得明确历史起点；接口异常时不误标为成功。
- [ ] 中途取消后断点保留，相同筛选再次运行可继续。
- [ ] 登录失效或权限错误会停止并提示，不重复请求。
- [ ] 图片、语音、视频和附件仅导出链接，不下载实体。
- [ ] 以 `= + - @` 开头的网页文字在 Excel 中保持为纯文本。

## 安全验收

- [ ] 工具只调用审核过的同源只读动作：`app.media.queryChatRecord` 与 `app.media.getSessionRecord`。
- [ ] 未修改标签、备注、状态、工单，未发送消息。
- [ ] 普通日志不包含 Cookie、Authorization、令牌或聊天正文。
- [ ] `清除未完成任务.bat` 不删除专用登录状态和已导出的 Excel。
- [ ] `清除专用登录状态.bat` 不删除任务断点和已导出的 Excel。
